# Molfar — головна (дизайн-макет)

Статична версія головної сторінки з полотна Claude Design.

- `index.html` — одна адаптивна сторінка: десктоп 1280–1920 (контейнер до 1440), планшет 768–1279, мобайл до 767
- `css/adaptive.css` — шар адаптиву й медіа-запити
- `1920.html` — перенаправляє на `index.html` (окрема версія більше не потрібна)
- `img/`, `fonts/` — фото, логотипи, шрифти NAMU Pro і e-Ukraine

Типографіка, відступи й кольори підігнані під токени дизайн-системи MOLFAR 2.0: кеглі за шкалою 12/14/16/20/24/32/40/48/80, line-height у %, відступи кратні 4px, без прозорих кольорів (крім затемнення фото).

Сторінка закрита від індексації пошуковиками (`noindex`, `robots.txt`).
